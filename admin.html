Pagos con tarjeta (Mercado Pago)

Con esto el cliente paga con débito, crédito o prepago al finalizar la compra, y el pedido pasa solo a «Pagado». Copia tu Access Token de producción desde Mercado Pago → Tu negocio → Configuración → Credenciales (o «Tus integraciones» → Credenciales de producción).

Correos automáticos al cliente

Si el cliente deja su email, le llega un correo cuando recibimos su pedido, cuando se paga, cuando se despacha (con la empresa y el número de seguimiento), cuando se entrega o si se cancela. Se envían con Resend (gratis hasta 3.000 correos al mes): crea una cuenta en resend.com, verifica tu dominio y copia aquí la API Key.

Tarifas de envío por región

El cliente ve el costo exacto en el carro según su región. Deja vacía una región para que el envío quede «a cotizar». Sobre el monto de envío gratis, el despacho no se cobra.
